A simple and modern weekly task management website for tracking team members' daily tasks and performance.

## Features
- Track daily tasks for two team members.
- Weekly task tracking (Monday–Sunday).
- Four-week navigation.
- Individual performance and efficiency tracking.
- Automatic data saving using LocalStorage.
- Backup and restore data.
- Print or save as PDF.
- Responsive design for mobile and desktop.

## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage
